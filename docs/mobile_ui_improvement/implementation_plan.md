# スマホ向けUI最適化・タッチ/ズーム操作改善・デプロイ実装計画

スマホ（携帯）での閲覧時におけるヘッダーの圧迫感解消、画像の拡大しやすさ向上、不要情報の非表示化を行い、最終的に動作検証・デプロイ・Gitプッシュまでを実施します。

## ユーザーレビューが必要な項目

> [!IMPORTANT]
> - **Gitリポジトリの新規作成**: 現在ローカルディレクトリに `.git` が存在しないため、`git init` を行い、GitHub上に新規リモートリポジトリ（例: `fanbox-gallery`）を作成してプッシュします。画像データなどの大容量フォルダは `.gitignore` に指定して除外します。
> - **Cloudflare Pagesへのデプロイ**: `npx wrangler@3 pages deploy dist --project-name=fanbox-gallery` を使用して既存の Cloudflare Pages プロジェクトへデプロイします。

## 概要と主な改善点

### 1. モバイル向けヘッダー & ツールバーの最適化・折りたたみ機能
- **コンパクト化**: スマホ表示（幅768px以下）ではロゴ、タブ、検索・ソートバーの余白やサイズを最小限に抑えます。
- **トグル（折りたたみ）ボタンの追加**: ヘッダー右上にコンパクトなトグルボタンを設置し、ワンタップでヘッダー・ツールバー全体を非表示（たたむ）/表示切り替えできるようにします。

### 2. モーダル（画像ビューア）のUIシンプル化 & 高度なタッチ/ズーム実装
- **フォーカスモード（全画面表示）**:
  - 画像領域または画面中央のタップで、ヘッダー・フッター・ナビゲーション矢印を一括でフェードアウト/フェードイン切替。画像鑑賞時の邪魔な情報を完全に排除できるようにします。
  - スマホ表示時、初期状態でヘッダーやフッターをアイコンのみのコンパクト表示にし、サムネイルリールもトグル式で折りたためるように改善。
- **スマホ向けタッチ＆ズームジェスチャー**:
  - **ダブルタップ**: 画像をスムーズに拡大 (2.5倍) / 復元。タップした位置を中心にズーム。
  - **ピンチイン / ピンチアウト**: 2本指でのマルチタッチ拡大・縮小対応。
  - **パン（ドラッグ移動）**: 拡大中の指ドラッグによる自由移動。
  - **左右スワイプ**: 1倍表示時のスムーズな前後画像切り替え。
  - **上下スワイプ**: 下方向にフリック/スワイプでモーダルを閉じる直感的な操作感。

### 3. スマホ表示での検証（実機風ブラウザ検証）
- ローカルサーバーを起動し、ブラウザサブエージェント（`browser_subagent`）にてモバイルビューポート（iPhoneサイズ等）で表示テスト・スクリーンショット撮影を行い、使いやすさを検証します。

### 4. ビルド・デプロイ・GitHubプッシュ
- `convert_and_build.py` による WebP 画像 & `dist` の生成。
- Git リポジトリの初期化と GitHub リモートへのコミット・プッシュ。
- Cloudflare Pages への `dist` ディレクトリデプロイ。
